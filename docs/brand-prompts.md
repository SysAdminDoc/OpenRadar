# OpenRadar Brand Directions

These prompts record the five directions considered for the first application icon. The app mark uses the Minimal direction.

## Minimal

Create a precise flat application icon for OpenRadar. Keep one circular globe with three bold grid curves, a radar center dot, a broad sweep wedge, and one compact storm echo made from three nested shapes. Use deep navy, cyan, sky blue, yellow, and red. Center the silhouette with generous transparent margin. Use PNG RGBA with fully transparent outside pixels. No text, gradients, shadows, mockup, 3D treatment, or watermark.

## App

Create a compact Windows weather radar app icon for OpenRadar. Combine a dark globe disc, cyan sweep beam, and small high-contrast storm cell. Use simple geometry that stays readable at 16 pixels. Keep the background fully transparent. No letters, text, gradients, gloss, bevels, or device mockup.

## Wordmark

Create an OpenRadar wordmark with a small circular radar globe at the left and a clean geometric sans-serif name. Use cyan and white on transparency with a single yellow storm accent. Keep spacing suitable for an About panel and repository header. No slogan, shadows, gradients, or mockup.

## Emblem

Create a circular OpenRadar emblem with a globe grid, radar sweep, and compact precipitation echo contained inside one clean ring. Use deep navy, cyan, yellow, and red. Favor broad shapes and a balanced silhouette. Transparent PNG, no text, gradients, shadows, or 3D effects.

## Abstract

Create an abstract weather radar mark from two crossing globe arcs, one rotating sweep wedge, and three nested storm echoes. It should suggest global navigation and live weather without copying an existing radar brand. Use flat cyan, sky blue, yellow, and red on transparency. No text, gradients, shadows, mockup, or watermark.
